## Question 1

**Is there a statistically significant difference in average minutes played between older and younger players?**

This analysis uses Python to compare the playing time of older and younger players using:

* Descriptive statistics
* Box plot and histogram
* Welch's t-test
* 95% confidence interval
* Cohen's d effect size
* Mann–Whitney U test

### Conclusion

The results show **no statistically significant difference** in minutes played between older and younger players. The observed difference was small and had a **negligible effect size**.

### Tools

Python, Pandas, NumPy, SciPy, Matplotlib, and Jupyter Notebook.
